# Documentation History

This directory contains tracked, browsable records of completed work. These
documents explain or reproduce prior decisions, but they are not authority for
new implementation; current contracts and gates remain under `docs/`.

- [`FOUNDATIONAL_CHARACTERIZATION_BASELINE.md`](FOUNDATIONAL_CHARACTERIZATION_BASELINE.md)
  preserves pre-foundation contact and encounter evidence.
- [`MULTI_ENEMY_PILOT_3_PLAN.md`](MULTI_ENEMY_PILOT_3_PLAN.md) preserves the
  completed Pilot 3 matrices and manual evidence.
- [`playtest/SHIPPED_REGRESSIONS.md`](playtest/SHIPPED_REGRESSIONS.md) preserves
  historical manual-regression prompts.

`docs/archive/` is intentionally ignored by Git and is reserved for local
recovery copies that are not useful to ordinary repository users. Git history
remains the recovery path for deleted stale material.
