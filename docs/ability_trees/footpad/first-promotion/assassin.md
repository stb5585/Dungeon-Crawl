# Assassin Ability Tree Implementation Reference

Status: `Finished`

Assassin has 25 nodes across utility, combat, status/death, stealth, and
counter disciplines. Its authored toxin economy, dagger/off-hand development,
openers, counters, and Cutthroat route feed Ninja without generic padding.
[Runtime diagram](assassin.svg).

Coating sources, application and severity, Hidden Blade ammunition, Death Mark
setup, path gates, and equipment interactions are covered by
`tests/core/test_assassin_toxins.py` and
`tests/core/test_thief_rogue_authored_kit.py`.
