# Archdruid Ability Tree Implementation Reference

Status: `Finished`

Tier: terminal. Breadth: 28 development nodes costing 30 points across four
seven-node affinity disciplines. [Current diagram](archdruid.svg). The 20
terminal-tier points buy 66.7% of the graph.

## Progression Shape

The four columns are Venom, Stone, Growth, and Storm. They contain seven nodes
each and preserve every existing spell. Poison Breath joins Vile Potion in
Venom, Expel Curse and Grove Pulse join Plant Seeds in Growth, Nature Shield anchors Stone,
and Bolt, Windswept, Ball Lightning, and Fourfold Surge form the active Storm
route. The Venom and Stone final masteries cost two points.

Grove Pulse deals Nature damage, restores half the damage as HP, and represents
Growth Harmony—or Venom when the target is already poisoned—through the
existing combat-only aspect system.

Each affinity's first memory talent adds one extra point whenever positive
attunement is earned for that affinity. This accelerates practice without
bypassing catalyst collection, Grove entry, the 99-point pre-ritual cap, or
the ritual that awakens an aspect.

## Boundaries And Acceptance

- Fourfold Balance state, catalysts, rituals, awakened aspects, and mastery
  rewards retain their existing save formats and gates.
- Aspect Harmony remains combat-only and distinct-aspect focused; Fourfold
  Surge retains its typed riders and immunity downgrade.
- The Class Ring preserves represented Harmony only through its existing rule.
  No tree node skips the Grove.
