# Demonologist Ability Tree Implementation Reference

Status: `Finished`

Demonologist has 24 nodes across contagion, contract mastery, Hellfire, soul
harvest, and demonic curses. Persistent patron contracts shape its class
mechanics while the ability tree controls compatible combat development.
[Runtime diagram](demonologist.svg).

Contract choice/state, corruption, bargains, curse interactions, save/load,
and presentation are covered by `tests/core/test_demonologist_contracts.py`.
